📖 Hướng Dẫn Lấy Dữ Liệu

1. Cách lấy Discord Token (Bắt buộc)

  1. Mở Discord trên trình duyệt web (Chrome/Edge) và đăng nhập.
  2. Nhấn F12 để mở Developer Tools, chuyển sang tab Network (Mạng).
  3. Gửi một tin nhắn bất kỳ vào server hoặc DM bạn bè.
  4. Trong danh sách Network, tìm request có tên messages hoặc science.
  5. Bấm vào request đó, nhìn sang bảng bên phải chọn tab Headers.
  6. Kéo xuống phần Request Headers, tìm dòng authorization. Copy toàn bộ chuỗi ký tự dài ngoằng đó (thường bắt đầu bằng chữ M hoặc N) và dán vào ô Discord Token.

2. Cách lấy Cookie cf_clearance (Bắt buộc)

  1. Vẫn ở trang web Discord trên trình duyệt, nhấn F12.
  2. Chuyển sang tab Application (Ứng dụng) ở góc trên Developer Tools.
  3. Ở cột bên trái, chọn Cookies -> https://discord.com.
  4. Tìm dòng có tên là cf_clearance.
  5. Copy phần Value (giá trị) của nó và dán vào ô cf_clearance Cookie.

3. Cách lấy Fingerprint (Tùy chọn)

Công cụ đã tích hợp sẵn script tạo Fingerprint tự động. Nếu He muốn tự làm thủ công, hãy xem file spoofer.py (hàm generate_fingerprint), copy đoạn script PowerShell và chạy trên máy Windows của bạn. Tuy nhiên, thông thường He chỉ cần bỏ trống ô này, tool sẽ tự động xử lý.

⚠️ Lưu ý: Không chia sẻ Token và Cookie cho bất kỳ ai. Mọi thông tin chỉ được lưu cục bộ trên máy của bạn.
